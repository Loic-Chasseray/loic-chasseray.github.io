Proofs

We need to know 4 methods of proof.

Proof by Deduction

Literally just using clear logical steps to conclude a result. This could be using soley algebra to show LHS = RHS or incorporating logical statements like "ODD * EVEN = EVEN".

Proof by Exhaustion

Breaking a proof into multiple cases and proving each case separately. It can be as simple as considering odd numbers then even numbers, or considering numbers that are a multiple of 3, 1 more than a multiple of 3, or 2 more than a multiple of 3.

Disproof by Counterexample

Any mathematical statement can be proven false by one counterexample. A starting example is to disprove the statement "All prime numbers are odd". The counterexample here is 2 because 2 is a prime number that is even.

Proof by Contradiction

This proof is more structured than the others:

  1. Assume that the opposite of the statement is true
  2. 'Do some maths'
  3. Find a result that is impossible
  4. Write a conclusion

Prove by contradiction the statement "a + b >= 2√(ab) for a >= 0, b >= 0"
Assume "a + b < 2√(ab)"
Then (a + b)^2 < (2√(ab))^2
a^2 + 2ab + b^2 < 4ab
a^2 - 2ab + b^2 < 0
(a - b)^2 < 0
But x^2 >= 0 for all x ∈ R
Hence we have arrived at a contradiction
So a + b >= 2√(ab) for a >= 0, b >= 0
