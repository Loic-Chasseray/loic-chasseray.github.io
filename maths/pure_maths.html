Proofs

We need to know 4 methods of proof.

Proof by Deduction

Literally just using clear logical steps to conclude a result. This could be using soley algebra to show LHS = RHS or incorporating logical statements like "ODD * EVEN = EVEN".

Proof by Exhaustion

Breaking a proof into multiple cases and proving each case separately. It can be as simple as considering odd numbers then even numbers, or considering numbers that are a multiple of 3, 1 more than a multiple of 3, or 2 more than a multiple of 3.

Disproof by Counterexample

Any mathematical statement can be proven false by one counterexample. A starting example is to disprove the statement "All prime numbers are odd". The counterexample here is 2 because 2 is a prime number that is even.

Proof by Contradiction

This proof is more structured than the others:

  1. Assume that the opposite of the statement is true
  2. 'Do some maths'
  3. Find a result that is impossible
  4. Write a conclusion

Prove by contradiction the statement "a + b >= 2√(ab) for a >= 0, b >= 0"
Assume "a + b < 2√(ab)"
Then (a + b)^2 < (2√(ab))^2
a^2 + 2ab + b^2 < 4ab
a^2 - 2ab + b^2 < 0
(a - b)^2 < 0
But x^2 >= 0 for all x ∈ R
Hence we have arrived at a contradiction
So a + b >= 2√(ab) for a >= 0, b >= 0

Derivations

We use many results and formulas, some from memorisation and some from the formula book. Here I will write my derivations, which are by no means formal proofs, but serve to build intuition about where they come from.

Compound-Angle Formulae

Sine (positive)

Starting with a geometric construction we can prove that
sin(α + β) = sin(α)cos(β) + cos(α)sin(β)

First, considering triangle AED, we see that sin(α + β) = ED / 1 = ED
Since ED = AG, we can say AG = sin(α + β)
Considering triangle AEC, we see that sin(β) = EC / 1 = EC
Also, we see that cos(β) = AC / 1 = AC
Let's label AG = sin(α + β), EC = sin(β) and AC = cos(β)

Next, by alternate angles, ∠BAC = ∠ACF = α
So, ∠FCE = 90 - α
Therefore, ∠FEC = α

Finally, considering triangle CEF we see that EF = cos(α)sin(β)
And considering triangle ABC we see that CB = sin(α)cos(β)
Since CB = FD, we can say FD = sin(α)cos(β)

Now that everything has been labelled, it is evident that AG = ED = EF + FD
Therefore, sin(α + β) = sin(α)cos(β) + cos(α)sin(β)

Cosine (positive)

Starting with a geometric construction we can prove that
cos(α + β) = cos(α)cos(β) - sin(α)sin(β)

First, considering triangle AED, we see that cos(α + β) = AD / 1 = AD
Since EG = AD, we can say EG = cos(α + β)
Considering triangle AEC we see that sin(β) = EC / 1 = EC
Also, we see that cos(β) = AC / 1 = AC
Let's label EG = cos(α + β), EC = sin(β) and AC = cos(β)

Next, by alternate angles, ∠BAC = ∠ACF = α
So, ∠FCE = 90 - α
Therefore, ∠FEC = α

Finally, considering triangle CEF we see that FC = sin(α)sin(β)
Since FC = DB, we can say DB = sin(α)sin(β)
Considering triangle ABC we see that AB = cos(α)cos(β)

Now that everything has been labelled, it is evident that EG = AD = AB - DB
Therefore, cos(α + β) = cos(α)cos(β) - sin(α)sin(β)

Tangent (positive)

Using the positive sine and cosine results we can prove that
tan(α + β) = (tan(α) + tan(β)) / (1 - tan(α)tan(β))

Since tan(θ) = sin(θ) / cos(θ)
tan(α + β) = sin(α + β) / cos(α + β)
tan(α + β) = (sin(α)cos(β) + cos(α)sin(β)) / (cos(α)cos(β) - sin(α)sin(β)) Dividing all terms by cos(α)cos(β) gives tan(α + β) = (tan(α) + tan(β)) / (1 - tan(α)tan(β))

Sine (negative)

We can use the positive result to derive the negative result
We also need the following results:

  • cos(-θ) = cos(θ)
  • sin(-θ) = -sin(θ)

We derived that sin(α + β) = sin(α)cos(β) + cos(α)sin(β) Replacing β with -β gives sin(α + (-β)) = sin(α)cos((-β)) + cos(α)sin((-β)) sin(α - β) = sin(α)cos(-β) + cos(α)sin(-β) sin(α - β) = sin(α)cos(β) - cos(α)sin(β)

Cosine (negative)

We can use the positive result to derive the negative result
We also need the following results:

  • cos(-θ) = cos(θ)
  • sin(-θ) = -sin(θ)

We derived that cos(α + β) = cos(α)cos(β) - sin(α)sin(β) Replacing β with -β gives cos(α + (-β)) = cos(α)cos((-β)) - sin(α)sin((-β)) cos(α - β) = cos(α)cos(-β) - sin(α)sin(-β) cos(α - β) = cos(α)cos(β) + sin(α)sin(β)

Tangent (negative)

Using the negative sine and cosine results we can prove that
tan(α - β) = (tan(α) - tan(β)) / (1 + tan(α)tan(β))

Since tan(θ) = sin(θ) / cos(θ)
tan(α - β) = sin(α - β) / cos(α - β)
tan(α - β) = (sin(α)cos(β) - cos(α)sin(β)) / (cos(α)cos(β) + sin(α)sin(β)) Dividing all terms by cos(α)cos(β) gives tan(α - β) = (tan(α) - tan(β)) / (1 + tan(α)tan(β))
